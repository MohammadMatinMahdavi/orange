# Orange AI portfolio videos

Place the three portfolio preview videos in this folder using these exact filenames:

- `project-01.mp4` — first portfolio card (Objects of desire)
- `project-02.mp4` — second portfolio card (Made to move)
- `project-03.mp4` — third portfolio card (A better first click)

The site references them at:

- `/videos/project-01.mp4`
- `/videos/project-02.mp4`
- `/videos/project-03.mp4`

Use MP4 encoded with H.264 video and AAC audio for broad browser support. Keep videos optimized for web delivery (ideally 1080p or lower and compressed). Videos autoplay muted, loop, and play inline. The only playback control shown is the sound toggle in the bottom-right corner of each card.
